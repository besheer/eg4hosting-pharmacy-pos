# eg4hosting pharmacy POS v0.6.2 — الأصناف والتقارير

نسخة تجريبية مبنية على v0.5.1، مع الاحتفاظ بإصلاح شاشة POS وبيانات الإصدارات السابقة.

## Windows
1. أغلق النسخة السابقة، وخذ نسخة احتياطية من `%LOCALAPPDATA%\PharmacyERP`.
2. فك الحزمة في مجلد جديد وشغّل `BUILD_EXE.bat`. يلزم Python 3.12 x64 وإنترنت على جهاز البناء.
3. افتح `dist\eg4hosting-pharmacy-POS-v0.6.2.exe`. يفتح المتصفح على http://127.0.0.1:8088
الـEXE الناتج يعمل بدون Python أو Docker على جهاز Windows مماثل. الحزمة تضم المصدر والبناء، وليست EXE مبنيًا ومختبرًا على Windows.
البيانات تبقى في `%LOCALAPPDATA%\PharmacyERP\data`، والنسخ في `backups` بنفس المجلد. لا تحذف البيانات لإجراء الترقية.

## Docker / Linux
```bash
docker compose up -d --build
```
الرابط http://localhost:8088. للترقية، أوقف النسخة القديمة وخذ نسخة من المشروع و`data` و`backups` ثم استبدل ملفات التطبيق وأعد البناء مع إبقاء البيانات.

حساب التطوير الافتراضي `admin / admin123`. متغير ADMIN_PASSWORD يطبق عند إنشاء الحساب لأول مرة فقط.

## استيراد الأصناف
من القائمة اختر **استيراد وتصدير الأصناف** بحساب Admin:
1. نزّل قالب Excel أو CSV.
2. احذف صف المثال وأدخل بياناتك؛ اجعل الباركود Text في Excel قبل الإدخال، خصوصًا للأصفار الأولى.
3. اختر «إضافة جديدة فقط» أو «إضافة وتحديث الموجود بالباركود».
4. ارفع الملف، وراجع المعاينة. إذا وُجدت أخطاء، نزّل تقرير الأخطاء وأصلحها ثم ارفع الملف مجددًا.
5. اعتمد الاستيراد. لا يطبّق أي صف قبل الاعتماد، ولا يتم استيراد جزئي لملف به أخطاء.

- CSV UTF-8 وExcel XLSX. ملفات XLS القديمة: احفظها XLSX أولًا.
- يقبل أسماء الأعمدة الإنجليزية بالقالب أو أسمائها العربية.
- المطلوب: `barcode`, `trade_name`, `sale_price`.
- اختياري: `active_ingredient`, `strength`, `dosage_form`, `manufacturer`, `reorder_level`.
- حدود الملف: 5 MB و10000 صف أصناف. ملفات Excel تُقرأ من الورقة النشطة فقط. الصيغ مرفوضة؛ استخدم قيمًا ثابتة.
- الأعمدة الاختيارية الغائبة لا تعدّل قيمة الصنف الموجود؛ الخلايا الفارغة في الأعمدة الموجودة تمسح النص أو تصفر حد الطلب.
- الباركود هو مفتاح المطابقة. التحديث لا يغير أرقام الأصناف الداخلية أو الفواتير القديمة أو المخزون.
- المعاينة صالحة 24 ساعة ومقيدة بالمستخدم. إذا تغير صنف منذ المعاينة يُرفض الاعتماد ويطلب رفع الملف مجددًا.
- نسخة SQLite احتياطية كاملة قبل الاعتماد، وسجل Audit للعملية. الاستيراد المعتمد مدعوم على SQLite في هذا الإصدار.
- استيراد الأصناف هو دليل المنتجات فقط. أدخل رصيد المخزون عبر المشتريات مع التشغيلة والصلاحية والتكلفة.

## تصدير الأصناف
CSV وXLSX لكل الأصناف أو نتائج البحث. XLSX يحفظ الباركود كنص. فتح CSV مباشرة في Excel قد يحوّل الباركود إلى رقم؛ الأفضل XLSX أو استيراد CSV مع تحديد نوع العمود Text. النصوص التي قد تُفسّر كمعادلات في CSV تُسبَق بعلامة اقتباس مفردة لحمايتها.

## مركز التقارير
من **التقارير**: اختر النوع والفترة والفرع والصنف، ثم عرض أو تصدير CSV/XLSX أو طباعة وحفظ PDF من المتصفح.

| التقرير | المحتوى |
| --- | --- |
| المبيعات والمرتجعات | الفاتورة والكاشير والصنف والكمية والقيمة والضريبة والتكلفة والربح |
| مجمل الربح حسب الصنف | صافي الكمية والمبيعات والتكلفة ومجمل الربح بعد المرتجعات |
| تحصيلات طرق الدفع | المدفوعات المسجلة نقدي/بطاقة/محفظة/بنك |
| المخزون والتشغيلات | الرصيد والصلاحية والتكلفة وقيمة المخزون |
| نواقص وإعادة الطلب | الرصيد الصالح وحد الطلب، بما فيه الأصناف بدون مخزون |
| قرب انتهاء الصلاحية | التشغيلات المنتهية أو التي تنتهي خلال 90 يومًا |
| حركة الأصناف | الحركات المؤرخة والكمية والسبب والمرجع |
| فواتير المشتريات | رقم الفاتورة والمورد والفرع والمبلغ |

- Admin يرى كل الفروع؛ مستخدم التقارير غير الإداري مقيد بفرعه. صلاحية التقارير متاحة لدور Accountant.
- المبيعات والمرتجعات تُحسب حسب تاريخ كل حدث، وليس بتحميل المرتجع على تاريخ البيع الأصلي. التواريخ الحالية مسجلة UTC.
- مجمل الربح = صافي المبيعات بدون ضريبة − تكلفة البيع المحفوظة. لا يشمل المصروفات، وليس صافي الربح المحاسبي.
- المبيعات القديمة بلا تكلفة محفوظة تظهر تكلفة وربح «—»، ومجمل الربح الإجمالي «غير مكتمل».
- تقارير المخزون والنواقص والصلاحية لحظية؛ فلاتر الفترة لا تحولها إلى رصيد تاريخي.
- تقرير الدفع من v0.5 فأحدث. لا يخصم مرتجعات واجبة الرد كأنها أموال صُرفت؛ صرف المرتجعات الفعلي غير موصول ببوابات الدفع.
- المشتريات تعرض الفواتير الأصلية قبل مرتجعات المورد. البحث بالصنف لا يطبق على تقريري المشتريات والدفع.
- الشاشة تعرض أول 500 نتيجة. التصدير وصفحة الطباعة يشملان كل النتائج المطابقة.
- جميع القيم بعملة التشغيل الواحدة؛ لا يوجد تحويل عملات أو دمج آمن لفواتير بعملات مختلفة.

## الحفاظ على البيانات والرجوع
الأصناف والمبيعات السابقة تبقى كما هي. الترقية تضيف جدول معاينات الاستيراد فقط.
للرجوع الكامل: أوقف التطبيق، واستعد نسخة التطبيق وقاعدة البيانات معًا من قبل التحديث. الاستعادة تستبدل العمليات التي حدثت بعدها؛ احتفظ بنسخة حديثة قبل الرجوع.

## التحقق والحدود
راجع VALIDATION.md. هذه نسخة MVP تجريبية وليست جاهزة لتشغيل سلسلة صيدليات إنتاجيًا. لا تزال تحتاج تأمينًا شاملًا للجلسات وCSRF والصلاحيات القديمة، ومزامنة فعلية بين الفروع واختبارات Windows وطباعة حقيقية. تعديل الفروع القديمة والصلاحيات خارج الوحدات الجديدة ليس ضمن هذا الإصدار.
التقارير الحالية مناسبة لحجم تجريبي/صغير؛ التصدير يحمّل النتائج في الذاكرة، وليس معالجة streaming لملايين الصفوف.
